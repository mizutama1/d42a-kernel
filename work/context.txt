■ 6. KernelSU 方針（重要）
  - KernelSU 公式 1.0+ は非 GKI 非対応。最終対応は v0.9.5。
  - 採用: KernelSU-Next `legacy` ブランチ（4.4〜6.x、manual hook 対応、v3.4.2）
  - 4.14 では以下が使えない/非推奨:
      CONFIG_KSU_KPROBES_HOOK … Kconfig に「5.10 未満では使うな」と明記
      CONFIG_KSU_SYSCALL_TABLE_HOOK … kernel >= 4.17 必須（本機は 4.14）
    → **CONFIG_KSU_MANUAL_HOOK=y** + カーネルソースへのパッチ（exec.c / open.c /
      read_write.c / stat.c / reboot.c 等）が本命。ソース入手後に適用。
  - 参考手順: https://kernelsu-next.github.io/webpage/pages/how-to-integrate-for-non-gki.html
  - 組込み: カーネルツリーで
      curl -LSs "https://raw.githubusercontent.com/KernelSU-Next/KernelSU-Next/next/kernel/setup.sh" | bash -s legacy
    （legacy ブランチが clone される）
  - 注意: 純正 config は STATIC_USERMODEHELPER_PATH="" なので ksud 実行は問題ない見込み
